# Agenda Electrónica de Contactos

Aplicación de escritorio orientada a la administración centralizada de contactos personales y profesionales. Diseñada bajo **Arquitectura Multicapas** para garantizar la modularidad del código, la escalabilidad y una clara separación entre la lógica de negocio, el acceso a datos y la interfaz de usuario.

## Características Principales
* **Gestión Completa (CRUD):** Registro, búsqueda, edición y eliminación de contactos.
* **Validación de Datos:** Reglas de negocio implementadas en capa intermedia para asegurar la integridad de la información ingresada.
* **Diseño Modular:** Estructura desacoplada que facilita el mantenimiento y la incorporación de nuevas funcionalidades.

## Tecnologías y Arquitectura
* **Lenguaje:** C#
* **Framework UI:** Windows Forms (.NET)
* **Patrón de Diseño:** Arquitectura Multicapas (Presentación, Lógica de Negocio, Acceso a Datos)

## Instalación y Ejecución
1. Clona este repositorio en tu máquina local.
2. Abre la solución (`.sln`) utilizando **Visual Studio**.
3. Si utiliza base de datos local, actualiza la cadena de conexión en el archivo `App.config`.
4. Restaura los paquetes NuGet (si aplica) y presiona `F5` para iniciar la aplicación.
